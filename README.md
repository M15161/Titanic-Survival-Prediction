# Titanic Survival Prediction

This project predicts passenger survival on the Titanic using machine learning.

## Project Overview
- Type: Classification
- Dataset: Titanic (Kaggle)
- Goal: Predict survival based on features like age, sex, class, etc.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- XGBoost (optional)
- Jupyter

## Models
- Logistic Regression
- Random Forest Classifier

## Results
Accuracy: ~78-82%  
Confusion Matrix and Classification Report are provided for evaluation.

## How to Run
1. Install the required libraries
2. Run the Jupyter Notebook
3. Check accuracy, plots, and feature importance
